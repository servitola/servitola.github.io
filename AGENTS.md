# servitola.github.io

A toy, not a blog: one static page, "What are you looking for?", with three answers opening as `#answers`,
`#dignity`, `#spider-man`. Plain HTML served by GitHub Pages; `.nojekyll` turns the Jekyll build off.

Illustrations come from fal.ai (`openai/gpt-image-2.5/sunburst/text-to-image`, 1024×1280) with one shared
style prefix: risograph, two inks `#efe6d4` and `#ff5a1f` on `#0f0e0c` paper. The page uses the same three
colors, so a new illustration has to be generated with that prefix or it will not sit on the page. Commit
WebP (`cwebp -q 82`), not the multi-megabyte PNGs.
